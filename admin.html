# পোশাক / পণ্য ক্যাটেগরি বিক্রয় মূল্য সাইজসমূহ স্টক স্ট্যাটাস অ্যাকশন

+ নতুন ক্যাটেগরি যোগ করুন

ওয়েবসাইটে কাস্টমারদের দেওয়া সকল ক্যাশ অন ডেলিভারি অর্ডারের পূর্ণাঙ্গ তালিকা।

সাইজ (Size Label) বডি / চেস্ট (ইঞ্চি) দৈর্ঘ্য / Length (ইঞ্চি) শোল্ডার (ইঞ্চি) হাতা / Sleeve (ইঞ্চি) অ্যাকশন
